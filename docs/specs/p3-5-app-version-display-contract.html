Contract: App Version Display

ADR-0049 · P3 #5 · 2026-06-15

§1 Context

User explicit request sau smoke test v1.7.0+2026061501: cần thấy app version trong Settings để verify bản đang chạy đúng là bản vừa install (không phải cache, không phải bản cũ).

Hiện tại: lib/views/settings_screen.dart chỉ có 1 section "Dữ liệu" (auto-purge switch). Không có UI hiển thị version ở bất kỳ đâu trong app.

Pattern reference: section header Row(Icon + Text) line 52-70, divider ListTile trailing Text(...) style.

§2 Decision

Thêm section mới "Thông tin" ở cuối SettingsScreen body ListView:

Visual mockup:

THÔNG TIN
Phiên bản 1.7.0 (build 2026061501)
  • Section header: icon Icons.info_outline 18px + text "THÔNG TIN" 12 semibold grey-600, same pattern như "Dữ liệu" section.
  • Row: ListTile hoặc Row trailing Text — dùng ListTile cho consistency với auto-purge switch ở trên, enabled: false để disable tap (read-only info).
  • Value format: {version}+{build} hoặc {version} (build {build}). Chọn dạng 2 để build number dễ nhìn hơn.
  • Source: package_info_plus — đã có sẵn trong pubspec (line trong pubspec.lock), không cần add dependency.

§3 Out of scope

  • Hiển thị database schema version (SQLite v15, backup v9) — đã show ở About dialog nếu có; user không request.
  • Tap row để copy version vào clipboard — YAGNI, nếu user cần sẽ request sau.
  • "What's new" link tới CHANGELOG — YAGNI per CONTEXT §Verify pass 2026-06-14.
  • Force update check / version comparison — không có server.

  • Mở Settings → scroll xuống dưới cùng → thấy section "Thông tin" → row "Phiên bản" → value "1.7.0 (build 2026061501)".
  • Row không tap được (read-only, info display).
  • Verify version thực sự match APK đã install: adb shell dumpsys package com.example.qlct | grep version hoặc flutter install output.
