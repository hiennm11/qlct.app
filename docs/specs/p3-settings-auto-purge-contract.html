§3 — Switch default + behavior

  • Default: ON. AutoPurgePrefs.isEnabled() returns true khi key chưa set.
  • On change: AutoPurgePrefs.setEnabled(value) + setState để update key annotation.
  • First launch: không có prompt. Setting tự load default ON.
  • No interval picker: 30 ngày hard-coded trong subtitle. YAGNI per grill.
  • last_purge_date key: defined trong auto_purge_prefs.dart nhưng chưa wire vào logic. Ngoài scope P3 #4.

§5 — Out of scope (P+ candidates)

Audit codebase 2026-06-14 — 6 domain areas user-configurable chưa có UI. Tất cả để P+:

  1. Theme (light only hiện tại, chưa có ThemeMode.dark)
  2. Currency (hardcoded VND, CurrencyFormatter chưa wire multi-locale)
  3. Auto-purge interval picker (7/30/90 ngày)
  4. Voice recognition language (hardcoded vi_VN trong voice_input_service.dart:48)
  5. Budget carry-over toggle (auto, no opt-out hiện tại)
  6. Clear all data (chỉ available qua restore flow)
