Contract: Weekly Review Card

ADR-0053 · Epic 4 · 2026-06-15

§1 Context

Mục tiêu Epic 4: tạo lý do để user mở app ít nhất mỗi tuần, không chỉ khi cần nhập giao dịch. Monthly Review hiện có (ADR-0021) mạnh nhưng cadence 30 ngày — quá thưa cho engagement ngắn hạn.

Cần 1 lớp insight ngắn hạn ngay trên Home (giữa Budget và Transactions, theo Option 1 grill session) — recap 7 ngày qua, không phải full review screen.

Pattern reference: BudgetOverviewWidget (alert-first collapse ADR-0014), StatsWidget._StatCard (tap-through, gradient), MonthlyReviewViewModel + MonthlyReviewBuilder (read-only derived, pure builder).

§2 Decision (overall)

Thêm WeeklyReviewCard widget + WeeklyReviewViewModel + WeeklyReviewBuilder + WeeklyReviewData model. Runtime-only (mirror Monthly Review ADR-0021) — không persist, không migration, không backup schema bump.

10th ChangeNotifier trong app, wired qua ChangeNotifierProxyProvider<ExpenseViewModel, WeeklyReviewViewModel> trong main.dart. Direct DataSource injection (Transaction + Budget + Recurring + Category) — không inject cross-VM (mirror ADR-0006 §Recurring).

§3 Week boundary + compare semantics

Quyết địnhSpec
Week start Mon-Sun (ISO 8601 calendar week, cố định boundary)
Week end (inclusive) Sun 23:59:59 local time
Current week range [weekStart(mon), min(now, weekEnd(sun))]
Previous compare range (current week in progress) Mirror ADR-0021 §Compare Period: same day-of-week-1 trước → cùng "hôm nay" tuần trước. Example Wed 2026-06-17: current [Mon 06-15, Wed 06-17], previous [Mon 06-08, Wed 06-10].
Previous compare range (past full week) Full [Mon, Sun] tuần trước — current week đã complete, không cần same-period.
prevWeekSpent = 0 case UI label "Chưa có dữ liệu tuần trước" (mirror Monthly Review "Chưa có dữ liệu tháng trước"). Suppress comparison chip.

§4 WeeklyReviewData model

Freezed immutable runtime model (mirror MonthlyReviewData). Không JSON serialization.

class WeeklyReviewData {
  // Boundary
  final DateTime currentWeekStart;     // Mon 00:00
  final DateTime currentWeekEnd;       // Sun 23:59 (or now if in progress)
  final DateTime previousCompareStart; // same-period previous week
  final DateTime previousCompareEnd;

  // Spending totals (exclude investment — mirror ADR-0021)
  final int weekSpent;                 // sum spending in current week
  final int prevWeekSpent;             // sum spending in previous compare range

  // Top category delta
  final String? topCategoryId;         // null nếu prev = current = 0
  final int topCategoryDelta;          // absolute VND delta, primary metric
  final int topCategoryCurrentSpent;
  final int topCategoryPrevSpent;
  final bool topCategoryNewlyIncurred; // true nếu prev = 0, current > 0

  // Days with activity
  final int daysLogged;                // 0-7, count days with ≥1 spending tx in current week

  // Largest transaction (all categories incl. investment — grill Q4 deviation)
  final WeeklyReviewLargestTransaction? largestTransaction;

  // Budget risk
  final List<String> budgetRiskCategoryIds; // categoryIds ở warning (≥80%) hoặc exceeded (≥100%)

  // Upcoming recurring
  final int upcomingRecurringCount;    // active rules với nextRunAt ∈ [now, now+7d]

  // Flags
  final bool hasEnoughDataForDelta;    // false nếu prevWeekSpent = 0 hoặc weekSpent = 0
  final WeeklyReviewLowDataState lowDataState;  // empty / low / normal
}

class WeeklyReviewLargestTransaction {
  final int amount;
  final String categoryId;
  final DateTime date;  // date only (bỏ time) — privacy
}

enum WeeklyReviewLowDataState {
  empty,   // 0 spending tx
  low,     // < 3 spending tx
  normal,  // ≥ 3 spending tx
}

§8 ViewModel state machine

enum WeeklyReviewLoadState { initial, loading, loaded, error }

class WeeklyReviewViewModel extends ChangeNotifier {
  WeeklyReviewLoadState _state = WeeklyReviewLoadState.initial;
  WeeklyReviewData? _data;
  String? _errorMessage;

  WeeklyReviewLoadState get state => _state;
  WeeklyReviewData? get data => _data;
  String? get errorMessage => _errorMessage;

  Future<void> load();    // mount + dirty invalidation
  void invalidate();       // called by ProxyProvider on ExpenseVM notify
  Future<void> refresh();  // pull-to-refresh explicit
}

3-state (loading/loaded/error) — empty derive từ data.lowDataState, không tách state riêng (ADR-0052 §3.1 lesson: tránh loading-state gap).

§9 Builder contract (pure, no I/O)

class WeeklyReviewBuilder {
  static WeeklyReviewData build({
    required List<Transaction> currentWeekTransactions,
    required List<Transaction> previousCompareTransactions,
    required List<Budget> budgets,
    required List<RecurringTransaction> activeRecurring,
    required List<Category> categories,
    required DateTime currentWeekStart,
    required DateTime currentWeekEnd,
    required DateTime previousCompareStart,
    required DateTime previousCompareEnd,
    required DateTime now,
  });
}
  • Pure function — không DataSource dependency, không ChangeNotifier, không side effects.
  • Input là pre-queried snapshots từ VM — không query full history vô hạn.
  • Spending aggregation: tx.where((t) => !t.category.isInvestment).fold(0, (sum, t) => sum + t.amount).
  • Days logged: distinct date set, exclude investment.
  • Top category: aggregate by categoryId (ADR-0036), exclude investment, find max by current - previous absolute delta.
  • Largest: tx.fold(max, ...) by amount — include investment (grill Q4).
  • Budget risk: filter budgets where spent/limit ≥ 0.8 (warning) or ≥ 1.0 (exceeded). Compute spent from currentWeekTransactions filter by categoryId.
  • Upcoming recurring: activeRecurring.where((r) => r.nextRunAt.isAfter(now) && r.nextRunAt.isBefore(now.add(Duration(days: 7)))).length.
  • lowDataState: empty if spending tx count = 0; low if < 3; normal otherwise.

§10b Auto-refresh behavior (ADR-0054)

Card tự refresh khi ExpenseViewModel notify (user add/edit/delete transaction qua QuickAddBar, TransactionEditDialog, TransactionDetailSheet, bulk delete). Không cần kill app hoặc pull-to-refresh.

  • Trigger chain: ExpenseVM.notify → ProxyProvider update → weeklyVM.invalidate() → _dirty = true + notifyListeners() → Selector rebuild → postFrameCallback → vm.load().
  • No-op guard: invalidate() bỏ qua nếu _dirty == true sẵn (tránh redundant rebuild khi ExpenseVM notify liên tục).
  • Idempotent: load() skip nếu data != null && !_dirty (mirror ADR-0050 settings pattern).
  • Failure handling: nếu load() throw → VM set errorMessage → widget render _ErrorView với retry button. Card KHÔNG silent fail.

§10c Parallel fetch (ADR-0054 §Perf)

5 queries song song qua Future.wait([...]) thay sequential await. Wall-clock cost giảm từ 5×T_query xuống 1×T_query (~80-100ms saved trên SQLite local).

  • Independent queries: 5 queries không có FK dependency tại fetch time → safe to parallelize.
  • Error semantics: nếu bất kỳ query fail, Future.wait throw ngay → outer try/catch set errorMessage (same như sequential). Error bubble như cũ.
  • Category fallback: nếu categoryDataSource.getAll() return empty → fallback seedCategories (ADR-0027 §10). Check empty sau Future.wait complete.

§12 Out of scope

  • Weekly Review full screen route (giống Monthly Review) — chỉ card trên Home, không route riêng.
  • Weekly Review history (cached past weeks) — YAGNI, MVP chỉ current week.
  • Weekly Review notification/push reminder — YAGNI.
  • Custom week start day (Sun-Sat) — chỉ Mon-Sun.
  • Weekly Review export/share — reuse Monthly Review pattern khi user request.
  • Days logged = "ngày user mở app" — analytics chưa track, chỉ count days có giao dịch.
