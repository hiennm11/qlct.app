ADR-0069 — Epic 6.1 Home: Super-Input

Tập trung 5 input methods (NoteEntry text + Voice + Quick template + Custom input + Quick category chip) lên 1 screen duy nhất, scroll dọc. Bỏ RecentTransactionsCard ở Home (vì user note liên tục → list update realtime = redundant). 1 nút Lưu chung sticky bottom. Bottom nav 4-tab + 3 hub screens giữ nguyên (ADR-0067 quyết định trước đó). Version bump: 1.8.0+2026061603 → 1.9.0+YYYYMMDDxx (MINOR — UX redesign Home, 0 breaking data layer).

§1 — Context: vì sao "super-input" Home

Sau Epic 6, user feedback 2026-06-16: (1) Home "chuối" vì TodayStrip + RecentTransactionsCard + NoteEntry cùng tồn tại, layout dày. (2) RecentTransactionsCard duplicate với TransactionHubScreen full list. (3) NoteEntry size quá nhỏ (maxLines=3), user muốn gõ nhiều hơn. (4) Note-first chưa thật sự "first" — QuickAddBar cũ 3-column compact có 3 mode (voice/quick/custom) bị loại bỏ ở Epic 6, user muốn restore nhưng không trở lại 3-column cũ — gộp tất cả 5 input methods thành 1 super-input trên Home. (5) Bottom nav 4-tab + 3 hub giữ nguyên vì user đã quen.

§2 — Layout tổng quan

Home = 1 SingleChildScrollView với 5 sections stack theo thứ tự ưu tiên (top = primary input). Sticky bottom = 1 nút Lưu chung.

§3 — _save logic (1 commit duy nhất)

Parse toàn bộ 5 input sources về 1 Transaction, validate, ExpenseViewModel.addTransaction. 

Future<void> _save() async {
  // 1. Nếu có note text → parse bằng VietnameseNumberParser.
  //    Nếu không có note text nhưng có _amount + _selectedCategory → dùng trực tiếp.
  final parsed = _noteText.isNotEmpty
      ? VietnameseNumberParser.parse(_noteText)
      : ParsedTransaction.empty();

  final amount = _amount.isNotEmpty
      ? ThousandSeparatorFormatter.parse(_amount)
      : parsed.amount;
  final category = _selectedCategory ?? catalog.findByName(parsed.categoryName);
  final note = _noteText.isNotEmpty ? _noteText : '';

  // 2. Validate.
  if (amount == null || amount <= 0) {
    _showError('Chưa nhập số tiền');
    return;
  }
  if (category == null) {
    _showError('Chưa chọn danh mục');
    return;
  }

  // 3. Build + add.
  final tx = Transaction(
    id: const Uuid().v4(),
    amount: amount,
    categoryId: category.id,
    date: DateTime.now(),
    note: note.isEmpty ? category.name : note,
  );

  final ok = await context.read<ExpenseViewModel>().addTransaction(tx);
  if (!ok) {
    _showError(context.read<ExpenseViewModel>().errorMessage ?? 'Lỗi không xác định');
    return;
  }

  // 4. Reset + undo support.
  _lastSavedTx = tx; // For undo.
  _resetForm();
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      key: const Key('super-input-save-snackbar'),
      content: Text('Đã lưu ${formatVnd(amount)} · ${category.name}'),
      duration: const Duration(seconds: 5),
      action: SnackBarAction(
        label: 'Hoàn tác',
        onPressed: () => _undoLastSave(),
      ),
    ),
  );
}

§4 — Voice flow (fill vào NoteEntry, user review trước Lưu)

Tap mic → bottom sheet voice modal. Parse xong → transcript fill vào NoteEntry. User có thể edit thêm trước khi bấm Lưu chung. 

Future<void> _startVoice() async {
  // 1. Check permission. Denied → show modal (ADR-0067 Q5 option B).
  final granted = await SpeechCoordinator.ensurePermission();
  if (!granted) {
    await showDialog<String>(
      context: context,
      builder: (_) => VoicePermissionDeniedDialog(),
    );
    return;
  }

  // 2. Open voice modal — same UX as Epic 6 (full screen, pulsing mic,
  //    interim transcript).
  final result = await showModalBottomSheet<VoiceParseResult>(
    context: context,
    isScrollControlled: true,
    builder: (_) => const VoiceInputModal(),
  );

  // 3. Parse result → fill NoteEntry, KHÔNG auto-save.
  if (result != null) {
    setState(() {
      _noteText = result.transcript;
      // Optional: pre-fill amount + category nếu parser detect.
      if (result.amount != null) _amount = formatVnd(result.amount);
      if (result.categoryId != null) {
        _selectedCategory = catalog.findById(result.categoryId);
      }
    });
    // Focus NoteEntry để user edit tiếp.
    _noteEntryFocus.requestFocus();
  }
}

§6 — _canSave predicate (Lưu button enable)

Lưu button enable khi có ÍT NHẤT 1 trong 3: amount hợp lệ / category đã chọn / note text parse được amount+category. 

bool get _canSave {
  if (_amount.isNotEmpty) {
    final v = ThousandSeparatorFormatter.parse(_amount);
    if (v != null && v > 0) return true;
  }
  if (_selectedCategory != null) return true; // Category + amount rỗng nhưng note parse ra amount
  if (_noteText.isNotEmpty) {
    final p = VietnameseNumberParser.parse(_noteText);
    if (p.amount != null && p.amount! > 0) return true;
  }
  return false;
}

§7 — Components bị xoá khỏi Home

  • RecentTransactionsCard — bỏ hoàn toàn (user note liên tục → list update realtime = redundant).
  • QuickAddBar — đã bỏ ở Epic 6, không restore.
  • StatsWidget — đã bỏ ở Epic 6, không restore.

TodayStrip được giữ lại ở dạng compact: true (1 dòng), đặt ở section 5 dưới Custom Input. Nội dung vẫn là "Hôm nay -X · Còn lại Y · progress bar 6px" như Epic 6. Source data giữ nguyên.

§8 — Components giữ nguyên

  • QuickAddBar, StatsWidget, JumpBar — đã bỏ ở Epic 6 (giữ nguyên quyết định).
  • 4 bottom nav tabs + 3 hub screens (TransactionHubScreen / BudgetHubScreen / AccountHubScreen).
  • ADR-0066 theme (teal pill, soft chip, Inter font).

§9 — Trade-offs

  • Home tràn dọc (full screen ~3-4 lần viewport): user phải scroll để thấy budget summary. Trade-off acceptable vì primary use case = ghi chép liên tục, summary chỉ glance nhanh.
  • 1 Lưu chung: trade-off giữa tốc độ (per-method auto-save) vs clarity (1 CTA). Chọn 1 CTA, user luôn biết bấm gì.
  • Voice fill NoteEntry thay vì summary card: tăng flexibility (user edit trước khi Lưu), trade-off là thêm 1-2s cho user scan/edit.
  • Quick category chip row 2 chung với mic: cluster "quick action" (1 tap = commit gần như xong). Trade-off: chip dễ bị mic che nếu 5+ chip — clamp max 5.
  • Remove RecentTransactionsCard: giảm redundancy. Trade-off: user không thấy "đã lưu" visual trên Home. Bù bằng snackbar "Đã lưu X" + 5s undo (Q10).

§10 — Edge cases

  • Voice permission denied: show modal VoicePermissionDeniedDialog (ADR-0067 Q5 option B), không disable mic button.
  • Quick templates empty: render EmptyTemplateStrip với 1 button "+ Tạo mẫu nhanh" mở TemplateCreateSheet.
  • Custom input note button: focus NoteEntry + scroll to top. Nếu NoteEntry đã focused → no-op.
  • Snackbar undo lúc đang gõ tiếp: undo restore form state, không conflict với input mới (dùng timestamp compare).
  • Form dirty + user back gesture: show confirm "Bạn có muốn huỷ giao dịch đang nhập?". Nếu không dirty → back bình thường.
  • Amount parse fail trong note text: vd "ăn cơm" → amount = null. _canSave false (trừ khi user nhập amount riêng). Snackbar lỗi khi tap Lưu.
