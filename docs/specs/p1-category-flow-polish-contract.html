§4 — Deferred: trash filter/search

Trạng thái: Deferred 2026-06-14 — không code trong phase này.

Lý do: canDeleteCategory guard chỉ cho phép soft-delete category không có financial references (transactions, budgets, snapshots, plans, recurring, templates). Trong thực tế, trash section thường có < 10 items (user cleanup misnamed categories). Search/filter cho 5-10 items là over-engineering — YAGNI.

Reopen trigger: User report có > 20 trash items thường xuyên, hoặc explicit feedback "trash khó tìm". Có thể revisit với filter theo name + sort theo deletedAt trong session tương lai.
