0083 — Voice Input v2: UX Pass

Modal redesign (mic icon to 96×96 tap-to-stop + 5 amplitude bars realtime + chip preview append-mode) + parser fuzzy (diacritic-insensitive + length-priority) + STT dictation mode (3s grace + 15s hard cap + vi_VN locale cứng + 4-tier fallback) + bỏ "Xác nhận" button (auto-fill NoteEntry, user bấm "Lưu" chung).
Preserve ADR-0069 "no auto-save" — voice path KHÔNG gọi ExpenseViewModel.addTransaction; fill NoteEntry để user bấm "Lưu" chung. Version bump: 1.9.0+YYYYMMDDxx → 1.10.0+YYYYMMDDxx (MINOR — UX/parser pass, 0 breaking data layer).

Parent ADR: 0083-voice-input-v2-ux-pass-2026-06-18.md

§1 — Context

User feedback 2026-06-18 (sau khi dùng Epic 6.3 Home với mic icon trên SuperInputCard):

  1. Modal chỉ có chấm đỏ pulse — không biết mic đang bắt được tiếng hay không.
  2. ListenMode confirmation cắt quá sớm khi user pause tự nhiên ("ăn ngoài 50 nghìn [pause 3s] và 20k cà phê" → STT chỉ emit 1 final).
  3. Parser chỉ exact-match substring → STT bỏ dấu ("an ngoai 50k") → không match "ăn ngoài" (có dấu).
  4. Substring bug: phrase "ăn" (Ăn ngoài) thắng "ăn nhà" (Ăn nhà) khi user nói "ăn nhà 50k" vì sortOrder tiebreak không đủ.
  5. Phải bấm "Xác nhận" thêm 1 lần trước khi đóng modal — friction thừa.
  6. Modal pop rồi show lại 1 lần khi finalResult emit → flicker visible.

§3 — State machine

enum VoicePhase { idle, listening, grace, closing }

// Coordinator state (_phase) transitions:
//   idle → listening         (user tap mic icon — coordinator._startVoiceInput)
//   listening → listening    (partial emit → append _transcript, reset bars+chip)
//   listening → grace        (finalResult 1 emit, transcript stable)
//   grace → listening        (new partial in 800ms → reset graceTimer, _transcript += partial)
//   grace → closing          (graceTimer fire 800ms no new partial)
//   listening → closing      (tap mic icon to = manual stop, override grace)
//   listening → closing      (hardCapTimer fire 15s)
//   listening → closing      (onError from STT)
//   closing → idle           (modal pop complete, _phase reset)
//
// VoiceInputService internal states (parallel):
//   uninitialized → initializing (await permission + init locale chain)
//   initializing → ready (tier 1-3 success) | failed (tier 4)
//   ready → listening (startListening called)
//   listening → ready (stopListening OR cancel OR finalResult auto-emit)
//   ready → uninitialized (dispose — coordinator disposed)

// Per-utterance (single user tap-to-stop) state trace (happy path):
//   idle (tap) → listening (chip='Đang nghe...')
//   listening (partial 'ăn ngoài 50') → listening (chip='ăn ngoài 50')
//   listening (partial 'ăn ngoài 50 nghìn') → listening (chip='ăn ngoài 50 nghìn')
//   listening (finalResult 'ăn ngoài 50 nghìn') → grace (chip='ăn ngoài 50 nghìn' xanh)
//   grace (no new partial 800ms) → closing (modal pop, NoteEntry fill)
//   closing → idle

// Empty path (auto-stop với transcript rỗng — STT timeout/permission bị revoke):
//   listening (finalResult '') → closing
//   closing (snackbar 'Không nhận diện...') → idle

// Hard cap path:
//   listening (15s elapsed) → closing (snackbar 'Quá thời gian tối đa')
//   → idle
