ADR-0067 — Epic 6 Home redesign

Thay thế Home hiện tại bằng "Balanced Note-First" (Stitch screen 9620c19063e74a1399efa4440f5ebb99, teal-balanced variant 31cf0f4a151d45f6a88c36f0b577bdba). Entry point: large note textarea + 3-5 quick chips + circular mic button. Hôm nay strip inline (spent + remaining + progress). Recent tx 3 rows compact. Bottom nav 4-tab (Tổng quan / Giao dịch / Ngân sách / Tài khoản) thay cho JumpBar floating 3-tab. Version bump: 1.7.1 → 1.8.0+YYYYMMDDxx (MINOR — new navigation structure + 3 hub screens, không breaking data layer).

§1 — Context: vì sao redesign Home

Epic 5 (month close) + Epic 4 (weekly review) đã add 2 cards trên Home. Home hiện đang dày đặc, JumpBar 3-tab floating chiếm diện tích. Stitch variant teal-balanced đã được user confirm (turn trước, 9 câu grill resolved) làm visual direction. Epic này ship entry-point + navigation để mỗi tab trở thành hub chuyên biệt (Overview = at-a-glance, Transactions = full list, Budget = monthly plan, Account = settings/profile).

§3 — Today strip (file mới lib/widgets/today_strip.dart)

Inline summary ngay dưới NoteEntry. 3 phần: spent (label) + remaining (label) + progress bar. 

// TodayStrip — at-a-glance spending vs remaining budget for today.
// Source: ExpenseViewModel.todayExpense (spending only, exclude investment).
//         BudgetViewModel.monthRemaining (current month total budget - spent).
//         todayProgress = clamp01(todayExpense / dailyAllowance).
//         dailyAllowance = monthRemaining / daysLeftInMonth.
class TodayStrip extends StatelessWidget {
  const TodayStrip({super.key});

  @override
  Widget build(BuildContext context) {
    return Consumer2(
      builder: (context, expVM, budVM, _) {
        final todaySpent = expVM.todayExpense;       // double, VND
        final monthRem = budVM.monthRemaining;        // double, VND
        final daysLeft = budVM.daysLeftInMonth;       // int
        final dailyAllowance = daysLeft > 0 ? monthRem / daysLeft : 0.0;
        final progress = dailyAllowance > 0
            ? (todaySpent / dailyAllowance).clamp(0.0, 1.0)
            : 0.0;

        return Card(
          key: const Key('today-strip'),
          child: Padding(
            padding: const EdgeInsets.all(16),
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(
                  'Hôm nay -${CurrencyFormatter.format(todaySpent)}',
                  key: const Key('today-strip-spent'),
                  style: theme.textTheme.titleMedium,
                ),
                const SizedBox(height: 4),
                Text(
                  'Còn lại ${CurrencyFormatter.format(monthRem)}',
                  key: const Key('today-strip-remaining'),
                  style: theme.textTheme.bodyMedium?.copyWith(
                    color: AppColors.textSecondary,
                  ),
                ),
                const SizedBox(height: 12),
                ClipRRect(
                  borderRadius: BorderRadius.circular(4),
                  child: LinearProgressIndicator(
                    key: const Key('today-strip-progress'),
                    value: progress,
                    minHeight: 6,
                    backgroundColor: AppColors.gray100,
                    valueColor: const AlwaysStoppedAnimation(AppColors.primary),
                  ),
                ),
              ],
            ),
          ),
        );
      },
    );
  }
}

Edge cases:

  • daysLeft == 0 (last day of month) → progress = 0, no div-by-zero.
  • dailyAllowance == 0 (no budget set) → progress = 0, strip renders neutral (not red).
  • monthRem < 0 (overspent) → progress = 1.0 max-clamped, show "Vượt X" label (toán: monthRem.abs()).
  • todaySpent == 0 → show "Chưa chi hôm nay" thay "Hôm nay -0đ".

§4 — Recent transactions card (compact 3 rows)

Inline trên Home. Load 3 transaction gần nhất từ ExpenseViewModel.allTransactions.take(3). Tap row → TransactionDetailSheet. Tap "Xem tất cả" → navigate to TransactionHubScreen. 

// RecentTransactionsCard — 3 most recent tx on Home, "Xem tất cả" CTA.
class RecentTransactionsCard extends StatelessWidget {
  const RecentTransactionsCard({super.key, required this.onSeeAllTap});
  final VoidCallback onSeeAllTap;

  @override
  Widget build(BuildContext context) {
    return Consumer(
      builder: (context, vm, _) {
        final recent = vm.allTransactions.take(3).toList();
        if (recent.isEmpty) {
          return const SizedBox.shrink(key: Key('recent-tx-empty'));
        }
        return Card(
          key: const Key('recent-tx-card'),
          child: Column(
            children: [
              ...recent.map((tx) => _RecentRow(tx: tx)),
              if (vm.allTransactions.length > 3)
                TextButton(
                  key: const Key('recent-tx-see-all'),
                  onPressed: onSeeAllTap,
                  child: const Text('Xem tất cả'),
                ),
            ],
          ),
        );
      },
    );
  }
}

Row layout: 56px height, emoji 32px + category name (1 line, ellipsis) + amount right-aligned. Per-row tap target ≥48dp (a11y). 0 separator — dùng border bottom 1px AppColors.border.

§7 — AppSettingsViewModel: thêm quickTemplateChipCount

Per grill Q6 (config flexible 3-5 chip thay vì cứng 3): user pin chip count trong Settings. Field mới thêm vào AppSettingsViewModel: 

// lib/viewmodels/app_settings_viewmodel.dart — add field
class AppSettingsViewModel extends ChangeNotifier {
  // ... existing autoPurgeEnabled (ADR-0050) ...

  static const int _chipCountMin = 3;
  static const int _chipCountMax = 5;
  static const int _chipCountDefault = 3;
  static const String _prefsKey = 'quick_template_chip_count';

  int _quickTemplateChipCount = _chipCountDefault;
  int get quickTemplateChipCount => _quickTemplateChipCount;

  /// Clamp to [3, 5] trước khi write.
  Future setQuickTemplateChipCount(int value) async {
    final clamped = value.clamp(_chipCountMin, _chipCountMax);
    if (clamped == _quickTemplateChipCount) return;
    _quickTemplateChipCount = clamped;
    await _storage.setInt(_prefsKey, clamped);
    notifyListeners();
  }
}

Settings ListTile (Q6 reply): thêm vào SettingsScreen section "Dữ liệu" (ADR-0047): Slider hoặc ListTile với 3 options (3 / 4 / 5 chip). Reactive qua Selector<AppSettingsViewModel, int> (ADR-0050 pattern).

Migration: 0 schema. SharedPreferences key mới default = 3. Existing user auto-migrate on first read.
