§2 — Action bar (3 actions)

Khi _selectionMode = true và _selectedIds.isNotEmpty, hiển thị bottom action bar với count + 3 buttons. Reuse pattern TransactionSelectionActionBar (line 172-177 của transaction_list_widget.dart).

ActionBehavior
Lưu trữ (N) Confirm dialog "Lưu trữ N danh mục?" → list tên → tap confirm → toggleArchive cho từng id. Snackbar "Đã lưu trữ N danh mục. Hoàn tác" 5s.
Xoá (N) Confirm dialog "Xoá N danh mục?" → tap confirm → softDeleteCategory cho từng id. Snackbar "Đã chuyển N vào thùng rác. Hoàn tác" 5s.
Hợp nhất (2) Chỉ enabled khi _selectedIds.length == 2. Tap → mở CategoryMergeSheet pre-select source = first selected, target = second selected. Snackbar undo per §3.

§3 — Undo path (Snackbar 5s)

Reuse pattern ADR-0008 (CONTEXT §Known Issues line 336-337): "Hoàn tác" SnackBar 5 giây cho destructive actions. Apply cho archive batch + delete batch.

Action gốcUndo behavior
Lưu trữ (N) Tap "Hoàn tác" → toggleArchive cho N id trở lại false. Snackbar ẩn.
Xoá (N) Tap "Hoàn tác" → restoreCategory cho N id (clear deletedAt). Snackbar ẩn.
Hợp nhất (2) Không undo trong snackbar (đã có trash restore path per ADR-0038). User restore source từ trash nếu cần rollback.

§4 — Auto-exit khi 0 selected

Edge case: user enter selection mode, toggle off tất cả selected rows. Behavior: _selectedIds.isEmpty trigger _selectionMode = false + clear state. Action bar ẩn ngay lập tức. Reuse pattern từ transaction_list_widget.dart:53.

Key binding:

§5 — Drag handle interaction (no conflict)

Active section có ReorderableDragStartListener ở trailing (line 313-319) cho drag-and-drop reorder. Trong selection mode, drag handle ẩn để tránh conflict với selection toggle tap area. Khi exit selection mode, drag handle render lại.
