# ADR-0044: P3 #1 — Bulk-archive Categories

**Status:** Accepted 2026-06-14
**Type:** Contract-ref (UX feature, không schema/dependency/release policy change)
**Linked contract:** `docs/specs/p3-bulk-archive-contract.html`

## Context

ADR-0037 §out-of-scope ghi "bulk-archive categories (reuses ADR-0009 multi-select pattern, no user demand yet)". Phase grill mới 2026-06-14 (sau 4 tuần P0 + P1 + P2 done) xác nhận có demand thật. Pattern multi-select đã có ở `TransactionListWidget` (ADR-0009, line 36 + 161). Reuse, không invent.

## Decision

Thêm multi-select cho Active + Archived sections ở `CategoryManagementScreen`. Long press enter selection mode, tap toggle, 3 actions ở bottom action bar: Lưu trữ / Xoá / Hợp nhất (chỉ enabled khi 2 selected). Confirm dialog + Snackbar undo 5s cho archive + delete (theo ADR-0008 pattern). Auto-exit khi 0 selected.

Mirror contract HTML 5 sections. Không tạo full ADR (5-15 dòng rule): không schema bump, không dependency change, không release policy change.

## Consequences

- 1 file thay đổi lớn: `lib/views/category_management_screen.dart` (StatelessWidget → StatefulWidget để giữ `_selectionMode` + `_selectedIds` state).
- New file optional: `lib/widgets/category_action_bar.dart` (mirror `TransactionSelectionActionBar` pattern). 
- VM không thay đổi — `toggleArchive` / `softDeleteCategory` / `mergeCategories` đã có.
- 0 schema migration. 0 dependency change. 
- Glossary: "Lưu trữ" + "Bỏ lưu trữ" đã có từ ADR-0037. "Hợp nhất" đã có từ ADR-0038. 0 term mới.
