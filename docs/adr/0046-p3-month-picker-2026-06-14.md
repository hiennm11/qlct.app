# ADR-0046: P3 #3 — Month Picker for Future Planning

**Status:** Accepted 2026-06-14
**Type:** Contract-ref (UX extension, không schema/dependency/release policy change)
**Linked contract:** `docs/specs/p3-month-picker-contract.html`

## Context

ADR-0026 ghi "no month picker beyond `currentMonth + 1`" (deferred). Phase grill mới 2026-06-14 chốt: AppBar nav ◀ Tháng MM/YYYY ▶, cap 12 tháng tới, copy từ `currentBudget` cho mọi target month, mỗi tháng 1 plan draft độc lập (DB key `yearMonth` per audit `sqlite_budget_plan_datasource.dart`). Bottom sheet "Tất cả plans" defer (YAGNI — month nav ◀▶ đủ để navigate).

## Decision

Mở rộng `MonthlyPlanScreen` + `MonthlyPlanViewModel` để user pick target month trong 1-12 tháng tới. AppBar có row nav. VM state: `targetMonth` ban đầu = `currentMonth + 1`, user dùng AppBar nav để thay đổi. Load draft theo `targetMonth` từ `sqlite_budget_plan_datasource`. Mirror contract HTML 5 sections. Không tạo full ADR (5-15 dòng rule): không schema bump, không dependency change, không release policy change.

## Consequences

- 2 file thay đổi: `lib/views/monthly_plan_screen.dart` (AppBar nav row) + `lib/viewmodels/monthly_plan_viewmodel.dart` (mutable `targetMonth` + reload method).
- 1 constant mới: `kMaxPlanningMonthsAhead = 12`.
- 0 schema migration. 0 dependency change.
- Glossary: "Kế hoạch tháng" đã có từ ADR-0026. "Kế hoạch tháng X" = target month = forward 1-12 tháng. 0 term mới.
