# ADR-0045: P3 #2 — Auto-purge Trash

**Status:** Accepted 2026-06-14
**Type:** Contract-ref (UX automation, không schema/dependency/release policy change)
**Linked contract:** `docs/specs/p3-auto-purge-contract.html`

## Context

ADR-0037 §out-of-scope ghi "auto-purge trash sau N ngày (background job + user setting required)". Phase grill mới 2026-06-14 chốt: 30 ngày retention (match existing UX copy), trigger mở app lần đầu trong ngày qua SharedPreferences flag, setting inline SwitchListTile trong trash section header, banner preview 5 ngày warning (25-30), confirm dialog tại ngưỡng 30. Restore từ backup = point-in-time snapshot → items purged "xuất hiện lại" đúng semantics.

## Decision

Thêm `purgeOldTrash(int retentionDays)` VM method + inline SwitchListTile setting + banner preview + confirm flow. Mirror contract HTML 6 sections. Không tạo full ADR (5-15 dòng rule): không schema bump, không dependency change, không release policy change.

## Consequences

- 2 file thay đổi: `lib/views/category_management_screen.dart` (SwitchListTile + banner) + `lib/viewmodels/category_viewmodel.dart` (purgeOldTrash method).
- 1 SharedPreferences key mới: `last_purge_date` (string yyyy-MM-dd).
- 0 schema migration. 0 dependency change.
- Glossary: "Tự động dọn rác" = new term. 0 conflict với existing "Xoá vĩnh viễn" (single action) hay "Khôi phục" (restore from trash).
- Backup impact: 0 code change. Restore merge semantics đã handle đúng (last-write-wins by `updatedAt` per CONTEXT §Khôi phục line 19).
